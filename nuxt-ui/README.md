# nuxt-ui

مشاريع Nuxt 4 مع Nuxt UI 4 و Tailwind 4: الإعداد والثيم ولوحات التحكم والعربي والتوليد الثابت.

| المهارة | شو بتعمل |
|---|---|
| `nuxt-ui` | الإعداد والثيم والمكونات والعربي RTL والـ SEO والنشر الثابت |
| `nuxt-ui-review` | فحص الموقع المبني بالمتصفح: فاتح وغامق وباللغتين، الروابط العميقة والطباعة |
