# laravel

كتابة كود Laravel: وين بيروح كل ملف بطريقة Domain-Driven Design، وكيف ينكتب الكود نظيف وآمن.

| المهارة | شو بتعمل |
|---|---|
| `laravel-ddd` | تقسيم الكود لطبقات Domain و Presentation: Actions و DTOs و Contracts و Services والكنترولر والمايغريشن والاختبارات |
| `laravel-code-quality` | جودة الكود والأمان والعمليات الحساسة وقائمة الأنماط الخاطئة وشكل تقرير المراجعة |
