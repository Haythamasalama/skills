# vue-inertia

واجهات Vue 3 مع Inertia و TypeScript و Tailwind 4 فوق Laravel، لأي مشروع جديد.

| المهارة | شو بتعمل |
|---|---|
| `vue-inertia` | تجهيز مشروع جديد، الصفحات والـ props والنماذج والقوائم والـ toasts والثيم والأيقونات والعربي RTL |
| `shadcn-vue` | تثبيت shadcn-vue وإضافة المكونات، الثيم والخطوط والوضع الغامق، الرسوم البيانية، ومشاكل RTL بالمكونات. بتنفع كمان مع Nuxt أو Vite |
| `vue-inertia-ui-review` | فحص الصفحات بالمتصفح بعد تسجيل الدخول: فاتح وغامق وباللغتين، النماذج والـ toasts والتنقل |
