# vue-inertia

واجهات Vue 3 مع Inertia و TypeScript و Tailwind 4 فوق Laravel، لأي مشروع جديد، بشكل وثيم جاهزين.

| المهارة | شو بتعمل |
|---|---|
| `vue-inertia` | مخطط المشروع كامل: المجلدات، الملفات من أول يوم، المكونات والـ composables، النماذج والقوائم والسجلات، الثيم والعربي RTL |
| `shadcn-vue` | تثبيت shadcn-vue، ملف الثيم الجاهز، كتالوج المكونات، الرسوم البيانية، ومشاكل RTL. بتنفع كمان مع Nuxt أو Vite |
