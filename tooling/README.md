# tooling

أدوات هذا الريبو نفسه. بتنزل على الجهاز كله مش على مشروع:

```bash
sh scripts/install.sh tooling --global
```

| الاسم | النوع | شو بيعمل |
|---|---|---|
| `skills-installer` | مهارة | بأي مشروع بتقول لـ Claude «نزّل مهارة X بهالمشروع» وهو بينزّلها من هون |
| `skill-publisher` | وكيل | بيحوّل أي شي لمهارة عامة ومستقلة ويضيفها للحزمة المناسبة |
