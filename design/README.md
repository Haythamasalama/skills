# design

تصميم بستايل آبل: المقاسات والألوان الدقيقة من كِت macOS 27 و iOS 27، ورسم شاشات ماك وآيفون للمواقع، وزجاج Liquid Glass على الويب.

| المهارة | شو بتعمل |
|---|---|
| `apple-macos-27-design` | قيم كِت آبل الرسمي لـ macOS 27: الألوان والخطوط والمواد والزجاج، ومقاسات وحالات كل مكوّن (أزرار، توولبار، سايدبار، نوافذ، قوائم، حقول) بالفاتح والغامق |
| `apple-ios-27-design` | قيم كِت آبل الرسمي لـ iOS 27: الألوان والخطوط و Dynamic Type والزجاج، ومقاسات كل مكوّن (توولبار، تاب بار، شيتات، قوائم، كيبورد، شريط الحالة، الشاشة الرئيسية) بما فيها iPhone Duo |
| `apple-screens` | قوالب HTML جاهزة لنافذة ماك وشاشة آيفون بقيم الكِت، وسكربت يحوّلها لصور PNG حادة بالفاتح والغامق وبالعربي من اليمين لليسار |
| `liquid-glass-web` | زجاج آبل على المواقع: توكنز للثيم الفاتح والغامق، وصفة الزجاج، أخطاء الثيمات الشائعة، رسم نافذة التطبيق بدل لقطة الشاشة، أيقونات بطبقات زجاج، وحركة بتحس إنها أصلية |
