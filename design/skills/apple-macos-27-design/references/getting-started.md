# Getting started with the kit — macOS 27

**Read when:** you are about to download Apple's macOS 27 UI Kit, open it, or publish work drawn from it.
**Owns:** the kit's own setup notes and licence terms, in summary, and what this skill ships.

Source: the "Getting Started" page of Apple's macOS 27 UI Kit (Figma community copy), read 2026-11-01.

- Using the Apple Design Resources means accepting the licence that comes with them. Read it before you use or share kit files.
- Install the latest SF Symbols before opening the kit; its glyphs are SF Symbols set as text.
- Send kit bugs and requests through Feedback Assistant.
- Design guidance (when to use which component) is in Apple's Human Interface Guidelines, "Designing for macOS".

What this skill ships: measured values and written descriptions only. It does not include the kit file, its artwork,
icons, wallpapers or a dump of its pages. Get the kit from developer.apple.com/design/resources.
