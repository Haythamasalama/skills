# Repurposing an article

Write social drafts **after** the article is published, keep each honest about what it links to,
and reuse the article's figures (exported as WebP, see `figures.md`). Keep drafts in a local folder
that is not committed.

Never publish a draft without the owner's explicit go in the same conversation; show the final text
and images first.

## X thread and LinkedIn post

X thread, five to eight posts:

```
1/ <The problem in one line, from the reader's side.> [figure: the before/after or the architecture]
2/ <What was hard about it.>
3/ <The idea that solved it.>
4/ <How it works, in one or two lines.> [figure: the key one]
5/ <A trade-off you made and why.>
6/ <What it changed.>
7/ <What you'd do differently.>
8/ The full write-up, with the figures: <link>
```

- One figure on the first post and one on the key post; the link goes in the last post.
- No hashtag walls.

LinkedIn post:

```
<Hook: three short lines. The problem or the surprising result.>

<Five to eight short lines on the idea and the result.
One line each. No bullets of buzzwords.>

<Optional: thanks to the colleagues who shared the work, by name.>

<Link to the article.>
```

- One figure.
- Colleagues may be named here (not on the site), as contributors.
- The employer rules in [writing-rules.md](writing-rules.md#employers-and-clients) hold.

## Medium

- Use Medium's **"Import a story"** with the published URL. It keeps the canonical link to your
  site, so search credits the original.
- Upload the figure exports as WebP in place of the site's inline SVG figures, and check that each
  one rendered.
- Keep a short notes file: the import date, what you changed after import, the Medium URL.

## LinkedIn Projects entry (for a case study)

| Field | Content |
|---|---|
| Project name | as on the card |
| Dates | start – end (or present) |
| Associated with | the employer or client |
| Project URL | the case study page |
| Media | the figure exports as WebP |
| Contributors | colleagues who shared the work |
| Skills | up to five |
| Description | under 2,000 characters, same rules as the page: goal, your role, what you did, the result. Count the characters |
